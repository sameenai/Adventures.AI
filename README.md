# Adventures.AI

AI-powered adventure planning platform. Share and discover world-class expeditions, plan trips with an AI assistant, and compare flights — all in one place.

The main application is **SummitSocial** (`summit-social/`), a full-stack Next.js 15 app.

---

## Prerequisites

| Tool | Version |
|------|---------|
| Node.js | 18+ |
| Docker + docker-compose | any recent version |
| npm | 9+ |

---

## Quick start

```bash
cd summit-social

# First-time setup: installs deps, creates .env, starts Docker,
# runs DB migrations, and seeds sample data
make setup

# Start the dev server (Docker must already be running)
make run
```

Open http://localhost:3000.

### Sign in locally

No OAuth credentials are needed. On the login page, use the **Local Dev** form:

- **Email** — any email address
- **Password** — `dev`

This creates the account on the fly. The seeded users (`alex@summitsocial.dev`, `maya@summitsocial.dev`, `james@summitsocial.dev`) are available with the same password.

## Environment variables

`make setup` copies `.env.example` → `.env` and generates `NEXTAUTH_SECRET` automatically. The only variables required to start are pre-filled:

| Variable | Default | Notes |
|----------|---------|-------|
| `DATABASE_URL` | `postgresql://summit:summit@localhost:5432/summitsocial` | Local Docker postgres |
| `REDIS_URL` | `redis://localhost:6379` | Local Docker Redis |
| `NEXTAUTH_SECRET` | auto-generated | Generated by `make setup` |
| `NEXTAUTH_URL` | `http://localhost:3000` | |

All other variables are optional for local development — the app falls back to mock data:

| Variable | Fallback behaviour |
|----------|--------------------|
| `OPENAI_API_KEY` | Streams a mock itinerary response |
| `AMADEUS_CLIENT_ID/SECRET` | Returns mock flight offers |
| `SKYSCANNER_API_KEY` | Returns mock flight offers |
| `GOOGLE_CLIENT_ID/SECRET` | OAuth button unavailable; use local dev login |
| `GITHUB_CLIENT_ID/SECRET` | OAuth button unavailable; use local dev login |

## Development

```bash
# Run dev server (requires Docker running)
make run

# Lint (Biome + TypeScript)
make lint

# Auto-fix lint issues
npm run lint:fix

# Unit tests
make test-unit

# Integration tests
make test-integration

# E2E tests (installs Playwright browsers on first run)
make test-e2e

# All tests
make test
```

### Database

```bash
make db-migrate   # Run pending migrations
make db-seed      # Re-seed sample data
make db-studio    # Open Prisma Studio at http://localhost:5555
```

### Deploy preview

```bash
make deploy-preview   # Deploys to Vercel preview URL
```

## Architecture

```
summit-social/
├── src/
│   ├── app/
│   │   ├── (auth)/          # Login and signup pages
│   │   ├── (dashboard)/     # Main app pages (adventures, leaderboard, flights, itinerary)
│   │   └── api/             # API routes
│   ├── components/
│   │   ├── ui/              # Primitives: Button, Card, Input, Modal
│   │   ├── shared/          # Navbar, Footer
│   │   └── [feature]/       # adventures/, chat/, flights/, leaderboard/, profile/
│   ├── hooks/               # useChat, useFlightSearch, useVote
│   ├── lib/
│   │   ├── ai/              # OpenAI client, prompts, tool definitions
│   │   ├── auth/            # NextAuth config (includes CredentialsProvider for local dev)
│   │   ├── db/              # Prisma client, Redis client + rate limiter
│   │   ├── flights/         # Amadeus + Skyscanner adapters, aggregator
│   │   ├── validators/      # Zod schemas for all API inputs
│   │   ├── logger.ts        # Structured logger (verbose in dev, errors only in prod)
│   │   └── constants.ts     # App-wide constants and enums
│   └── middleware.ts        # API request logging in development
├── prisma/
│   ├── schema.prisma
│   └── seed.ts
└── docker-compose.yml       # Postgres 16 + Redis 7
```

**Key data flows:**
- **Adventures** — RSC pages fetch from Postgres, votes persisted via optimistic client updates + API
- **AI Chat** — Streams GPT-4o (or mock) via SSE; conversation history stored as JSON on the `Itinerary` model
- **Flights** — Amadeus + Skyscanner queried in parallel, results cached in Redis for 15 min
